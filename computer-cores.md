## Work-in-Progress Computer Core Releases

This is a list of Cores that are not finalized yet and need more testing and might get several updates every week. Therefore we only put links to the Discord and the Github issues page, but no direct download links here. 
Expect errors, missing menu items or other strange effects. Please test and post your issues, _preferably to the Github issues_, so that the developers can follow up.
Cores marked as **wants more testing** already have a couple of users testing and submitting reports. **NEEDS testing** is for Cores that really have not enough people yet testing and filing reports.
